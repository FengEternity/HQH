# 运营入口：小程序码与本机回访

日期：2026-10-22  
状态：待实现  
载体：`miniprogram/pages/mine/mine`、`README.md` 的「运营入口」  
范围：本机登录过才在「我的」显示工作台。冷启动用指向登录页的小程序码。首页标题连点 8 次保留。口令、票据、云函数和工作台内容不变。

## 1. 要解决什么

运营要进得去，普通用户的界面上不出现运营入口。现在只有首页标题连点 8 次，难记，也不是安全边界。安全边界仍是口令和云函数票据。

## 2. 冷启动

小程序码打开 `pages/admin/login/login`。这个页面已经在 `app.json` 里。

码不由小程序生成，也不写入仓库。已发布版本在微信公众平台生成，页面路径填 `pages/admin/login/login`，只发给运营。公众平台的码若不能填页面路径，就用能指定路径的小程序链接，打开的仍是这个登录页。

这种码打开的是已发布代码。体验版成员在对应正式版发布前，仍用首页标题连点 8 次进入登录页。

## 3. 本机回访

「我的」在资料卡和底部版本之间，本机存有运营票据时显示一行「运营工作台」，右侧是「进入」。用现有的 `hub-item`。没有票据时这一行不渲染。

票据沿用 `hqh_admin_ticket`。登录成功时写入，过期后仍留在本机。不新增第二个标记，过期时也不删除这串票据。因此这台微信只要成功登录过，这一行就还在；清除小程序缓存后，要再用小程序码或连点进入并登录，这一行才回来。

点这一行进入 `/pages/admin/login/login`。登录页已有的检查保持不变：票据仍有效就进入工作台，无效就留在口令页。每次显示「我的」时重新读票据。

底部版本仍只显示版本文字，不能点。首页标题连点 8 次仍打开登录页。

## 4. 不改什么

- 不改口令、票据有效期、云函数和管理页的鉴权。
- 不在小程序里做生成码、保存码或分享码。
- 不把运营入口放进底栏，也不在未登录过的「我的」里留占位。
- 不改工作台、关于页和客服页。

## 5. 测试

`miniprogram/pages/mine/mine.test.js`：

- 没有票据时不显示「运营工作台」；有票据时显示，点击进入 `/pages/admin/login/login`。
- 底部版本没有点击行为。
- 现有的资料编辑断言保持通过。

## 6. 验收

1. 一台从未登录过运营的微信打开「我的」，只有资料卡和版本。
2. 这台微信登录成功后再打开「我的」，资料卡下方有「运营工作台」。票据过期后这一行仍在，点进去是口令页。
3. 票据仍有效时，点这一行会进入工作台。
4. 首页标题连点 8 次仍进入登录页。
5. README 的「运营入口」写明三条路：小程序码或指定路径的小程序链接、本机「我的」、首页标题连点 8 次。
