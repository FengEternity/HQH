# AI 搜片 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 小程序首页增加「AI 搜」，本机 8787 用 OpenAI 兼容 Chat+Embedding 做问句改写、语义召回和跳段落，不接微信云。

**Architecture:** 纯函数在 `cloudfunctions/catalog/lib/aiSearch.js`；HTTP 封装在 `scripts/openaiCompat.js`；离线 `scripts/embed-catalog.js` 写 `miniprogram/data/ai-index.json`；`preview-server` 暴露 `POST /api/ai-search`；小程序只负责按钮、结果卡和播放 `t` 秒。

**Tech Stack:** Node 内置 `node:test` / `fetch` / `http`；微信小程序 `wx.request`；无新 npm 依赖。

## Global Constraints

- 不调用微信云函数、不把 `OPENAI_API_KEY` 写入仓库或小程序包
- 列表响应不下发 `transcript` 全文
- AI 搜失败不回退关键词搜
- 上游合计超时 20s
- `startSec` 必须来自候选切片，禁止 LLM 虚构秒数
- 默认 Chat 模型 `deepseek-chat`，默认 Embed 模型 `text-embedding-3-small`（须同一兼容网关同时支持；否则脚本失败）
- 不在本任务内 `git commit`（除非用户另行要求）

### Task 1: 纯函数检索核（TDD）

**Files:**
- Create: `cloudfunctions/catalog/lib/aiSearch.js`
- Test: `cloudfunctions/catalog/lib/aiSearch.test.js`

**Interfaces:**
- Produces:
  - `cosine(a: number[], b: number[]): number`
  - `videoIndexText(video): string`（摘要优先，否则 title+intro+transcript，截断 8000 字）
  - `topK(items, k): items`
  - `mergeVideoScores(videoHits, segmentHits): Array<{videoId, score, bestSegment}>`  
    `score = 有切片 ? 0.6*video + 0.4*bestSeg : video`；无 video 命中但有 segment 时 video 分按 0 再算
  - `sanitizeStartSec(requested, candidateSecs): number`（requested 须在 candidateSecs 内，否则取 candidateSecs[0] 或 0）
  - `excerpt(text, maxLen=40): string`
  - `formatStartLabel(sec): string`（`约 m:ss`；sec 为 0 仍显示约 0:00；无秒则 `''`）
  - `filterIndexByBrand(index, catalogVideos, brandId)`
  - `applyLlmPicks(ranked, llmPicks): ranked`（对齐 `_id`，写入 reason/startSec 并 sanitize）
  - `runAiSearch(opts): Promise<{ok, code?, message?, answer, videos}>`（见 Task 3 调用方）

### Task 3: `runAiSearch` + `POST /api/ai-search`

**Files:**
- Modify: `cloudfunctions/catalog/lib/aiSearch.js`（`runAiSearch`）
- Modify: `scripts/preview-server.js`

**Interfaces:**
- `runAiSearch({ query, brandId, index, catalogVideos, chatJson, embedTexts, timeoutMs: 20000 })`
  1. trim query 空 → `{ ok:false, code:'BAD_INPUT' }`
  2. 无 index.videos → `{ ok:false, code:'NO_INDEX' }`
  3. Chat 改写：`{"query":"","keywords":[]}`，失败则 `searchText = 原 query`
  4. `embedTexts([searchText])` 失败 → `{ ok:false, code:'EMBED_FAIL' }`
  5. brand 过滤后 video/segment 各 Top-8 余弦
  6. merge 取 Top-5；组装候选 `{_id,title,intro,brandName,posterUrl,localFile,segments:[{startSec,endSec,text}]}` 再 Chat 一次：输出 `{"answer":"","picks":[{"_id","reason","startSec"}]}`；startSec 必须 sanitize
  7. 卡片：`excerpt` 来自命中切片；无切片 `startSec=0` 且 excerpt 用 intro 截断；**不**含 transcript 全文

preview-server：`POST /api/ai-search` 读 body `{query,brandId}`，加载 ai-index（每次请求 `readFileSync`，缺文件当 NO_INDEX），调用 `runAiSearch`。无需 admin token。

- [ ] **Step:** 用假 `chatJson`/`embedTexts` 的单测覆盖改写失败仍能搜、虚构秒数被丢掉。
