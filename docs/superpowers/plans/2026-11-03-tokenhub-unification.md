# TokenHub 调用统一

状态：本地实现与离线验收已完成，云端与真机待验收。用户已选择统一 TokenHub；在 `dev-agent-core` 延续当前播放页功能，不合并远端搜索分支，不发布。

## 目标与边界

- 播放页问答、运营模型测试与视频简介使用同一 TokenHub 调用实现。
- 提供 Embedding 接口供独立搜索分支迁移；本次不提前合并该分支及其鉴权、索引任务改动。
- 语音识别保持腾讯 ASR 协议。模型调用统一不改变视频可见性、人员身份、客服状态或商品权限。
- 缺少配置属于明确的未就绪状态；开发与离线验证不依赖本机持有云端密钥。实际验证使用运营工作台的服务端测试入口。

## 接口与配置

- `shared/ai-runtime` 为唯一调用源码，提供 chat、embed、真实取消、期限、脱敏错误与用量。通过同步脚本生成云函数和容器内的发布副本，检查漂移。
- 接入配置统一使用服务端 `TOKENHUB_BASE_URL`、`TOKENHUB_API_KEY`；场景模型优先读取 `admin_config/agent_models`，再读取对应环境配置。凭据不进入数据库、客户端或 Trace。
- 不同云函数与容器的环境变量并不共享：部署说明必须列出每个调用运行时的注入和验证要求，不能声称可自动复用现有容器凭据。
- 运营页面显示当前服务端接入就绪状态，并使用相同 TokenHub 客户端测试模型；未就绪时给固定配置提示，供应商正文不返回客户端。
- 问答工具循环保持在 Agent 适配中，只执行固定的当前视频只读工具。共享客户端只做一轮供应商请求。

## 实施与验收

1. 先用失败测试覆盖 TokenHub 工具请求、配置缺失、错误脱敏、总超时和向量校验，再实现共享客户端及发布同步。
2. 替换 CloudBase 生文执行器和测试入口；保留模型选择与作用域，验证工具上限、卡片白名单及真实 HTTP 格式。
3. 视频简介复用共享客户端，保持现有提示词、审核和 ASR；同步配置就绪显示及部署文档。
4. 运行相关回归、完整本地测试与发布副本检查。能访问云环境后从云端做最小模型测试，再做真机问答验收。
