# 首页封面 16:9 裁剪 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 运营选封面或视频首帧时在独立页按 16:9 拖动缩放后导出 `1280×720` JPEG；首页卡片、编辑预览、运营列表缩略图同一比例，新封面不再被容器额外上下裁切。

**Architecture:** 几何与导出源矩形放在纯函数 `miniprogram/utils/coverCrop.js`。裁剪页只做手势、canvas 出图、通过 eventChannel 回传临时路径。编辑页在上传前打开裁剪页；展示端只改 CSS 为 16:9，`<image>` 仍用 `aspectFill` 兜底旧图。不改 catalog 换链。

**Tech Stack:** 微信原生小程序（基础库 3.7.1）、canvas 2d、`wx.canvasToTempFilePath`、`node --test`。

## Global Constraints

- 比例 16:9；导出 JPEG `1280×720`，质量约 0.8。
- 缩放最小为短边铺满取景框（不能露空白），最大为最小缩放的 4 倍。
- 拖动后图片必须始终盖住取景框。
- 原图任一边小于 640px 时 toast 提示可能发糊，仍允许确认。
- 取消 / 返回不改已有 `coverFileId` 与预览。
- `planVideoCoverUpload` 动作名不变：`keep` / `upload_thumb` / `missing_thumb`。
- 不改云存储 ACL、`getTempFileURL`、不新增封面数据库字段。
- Commit message 用简体中文，不要写 `DES-*` / `ANAL-*`。
- 在 **`dev`**（或从 `dev` 拉的短分支）上执行，不要在 `main` 上开发。
- 规格：`docs/superpowers/specs/2026-09-10-cover-16x9-crop-design.md`。

```js
'use strict';

const COVER_RATIO = 16 / 9;
const EXPORT_WIDTH = 1280;
const EXPORT_HEIGHT = 720;
const MAX_SCALE_FACTOR = 4;
const SMALL_EDGE = 640;

function minScale(imgW, imgH, frameW, frameH) {
  return Math.max(frameW / imgW, frameH / imgH);
}

function clampScale(scale, min) {
  const max = min * MAX_SCALE_FACTOR;
  if (scale < min) {
    return min;
  }
  if (scale > max) {
    return max;
  }
  return scale;
}

function clampOffset(offsetX, offsetY, scale, imgW, imgH, frameW, frameH) {
  const dw = imgW * scale;
  const dh = imgH * scale;
  const minX = Math.min(0, frameW - dw);
  const minY = Math.min(0, frameH - dh);
  return {
    offsetX: Math.min(0, Math.max(minX, offsetX)),
    offsetY: Math.min(0, Math.max(minY, offsetY)),
  };
}

function initialView(imgW, imgH, frameW, frameH) {
  const scale = minScale(imgW, imgH, frameW, frameH);
  return {
    scale,
    offsetX: (frameW - imgW * scale) / 2,
    offsetY: (frameH - imgH * scale) / 2,
  };
}

function sourceRect(offsetX, offsetY, scale, imgW, imgH, frameW, frameH) {
  let x = Math.round(-offsetX / scale);
  let y = Math.round(-offsetY / scale);
  let width = Math.round(frameW / scale);
  let height = Math.round(frameH / scale);
  if (x < 0) {
    x = 0;
  }
  if (y < 0) {
    y = 0;
  }
  if (x + width > imgW) {
    width = imgW - x;
  }
  if (y + height > imgH) {
    height = imgH - y;
  }
  if (width < 1) {
    width = 1;
  }
  if (height < 1) {
    height = 1;
  }
  return { x, y, width, height, destWidth: EXPORT_WIDTH, destHeight: EXPORT_HEIGHT };
}

function isSmallCover(imgW, imgH) {
  return imgW < SMALL_EDGE || imgH < SMALL_EDGE;
}

module.exports = {
  COVER_RATIO,
  EXPORT_WIDTH,
  EXPORT_HEIGHT,
  MAX_SCALE_FACTOR,
  SMALL_EDGE,
  minScale,
  clampScale,
  clampOffset,
  initialView,
  sourceRect,
  isSmallCover,
};
```

```js
function openCoverCrop(src) {
  return new Promise((resolve) => {
    let settled = false;
    const finish = (value) => {
      if (settled) {
        return;
      }
      settled = true;
      resolve(value);
    };
    wx.navigateTo({
      url: '/pages/admin/cover-crop/cover-crop',
      events: {
        done: (payload) => finish((payload && payload.path) || null),
        cancel: () => finish(null),
      },
      success: (res) => {
        res.eventChannel.emit('init', { src });
      },
      fail: () => finish(null),
    });
  });
}
```

## 手测（实现后）

1. 横屏 16:9 图：裁剪页几乎铺满，确认后首页标题完整。
2. 竖图：默认中段，上移后顶部字进框，首页与编辑预览一致。
3. 只传视频：进裁剪；取消不写封面。
4. 已有封面点更换后取消：仍显示旧封面。
5. 旧封面未重传：首页仍显示。
6. 导出失败（可在真机断 canvas）：停在裁剪页，不覆盖封面。
